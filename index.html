HOW SURFSENE WORKS

เลือกบริการให้เหมาะกับงาน

01

เช่าเครื่องมือวัด

Electrical, Power Quality, Temperature, Humidity, Environmental, Vibration และ Sensor อุตสาหกรรม จัดเป็น Kit พร้อมใช้งาน

02

เช่า Gateway

เชื่อม Meter, PLC, Machine หรือ Sensor เดิมผ่าน Modbus RTU/TCP, OPC UA และ Protocol ที่รองรับ เพื่อนำข้อมูลขึ้น SURFSENE

03

ติดตั้งถาวร

สำรวจ ออกแบบ Supply, Install, Commission ระบบ Meter, Sensor, Gateway, Network และ Dashboard สำหรับ Monitoring ระยะยาว
